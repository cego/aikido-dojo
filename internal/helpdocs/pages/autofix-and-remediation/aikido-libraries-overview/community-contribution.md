# Community Contribution

All Aikido patches are freely available and accessible. This is consistent with the open source licenses of the patched libraries and reflects Aikido's commitment to the open source ecosystem.

Most patches are built on existing upstream fixes. Maintainers sometimes choose not to backport a fix to an older version of a package, leaving users of that version exposed. Aikido fills that gap by creating and distributing the backport.

When Aikido Intel identifies a CVE before the upstream maintainer does, Aikido engages with the maintainer directly and contributes the available fix.
