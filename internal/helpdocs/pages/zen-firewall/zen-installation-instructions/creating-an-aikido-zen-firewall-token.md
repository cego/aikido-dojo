# Creating an Aikido Zen Firewall Token

1. [Create your Aikido account](https://help.aikido.dev/getting-started/setting-up-your-account) if you haven't done so already
2. Go to the [**Zen** section](https://app.aikido.dev/runtime/services?regionRedirect=1) in Aikido.
3. Click on **Add app**.
4. Choose a name for your app and click **Generate token**.
5. Copy the generated token
