# Connecting multiple BitBucket Data Center Projects to a single workspace

* Make sure you already have a BitBucket Server workspace connected to Aikido.
* Once you are on the Aikido feed of the currently connected BitBucket Server workspace, go to <https://app.aikido.dev/onboarding/bitbucket-server/connect-multiple-projects>
* Select the Projects you'd like to link to the current Aikido workspace and click 'Save'
* Aikido will now import the accessible repositories of all linked Projects. This can take a few seconds.
* Select the repositories you'd like to scan and click 'Next'.
