# Kertos Integration

The Kertos integration syncs Aikido issues to Kertos, so you can track vulnerability remediation SLAs for your compliance program.

## How it works

You set up the connection in Kertos. Aikido links to the Kertos guide from the integrations page.

## Set up the Kertos integration

{% stepper %}
{% step %}
### Open the Kertos card

In Aikido, go to [Settings > Integrations](https://app.aikido.dev/settings/integrations?regionRedirect=1) and find **Kertos** in the **Compliance** section.
{% endstep %}

{% step %}
### Follow the Kertos guide

Click **Connect**. Aikido opens [Tracking vulnerability remediation SLAs with Aikido](https://docs.kertos.io/articles/9091503218-tracking-vulnerability-remediation-slas-with-aikido) in Kertos' documentation. Follow the steps there to connect your Aikido workspace.
{% endstep %}
{% endstepper %}
